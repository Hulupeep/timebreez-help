# Leave Admin

**Who uses it:** admins. In the menu: **Leave Admin**.

## What it does

One page with a link to everything you need to run leave. Nothing is set on this page itself: it only takes you to the right place.

| Link | Where it goes | What you do there |
|---|---|---|
| Leave Requests | [Leave Requests]({{ site.baseurl }}/docs/app/leave-requests/) | Review, approve and deny time-off requests |
| Leave map | [Wallchart]({{ site.baseurl }}/docs/app/wallchart/) | See who is off and when, across the whole team |
| TOIL | [Time in Lieu]({{ site.baseurl }}/docs/app/toil/) | Track and adjust time-in-lieu balances |
| Settings | [Settings, Leave Setup]({{ site.baseurl }}/docs/app/settings/) | Change the default allowance, the leave year and the calculation rules |

## Setup checklist

While your organisation is not fully set up for leave, a checklist shows at the top of the page. Work through it first. It disappears once everything is set. The four links stay on the page either way, so you can always get back to Leave Setup.

## Common questions

**I am a staff member and this page sends me to My Leave.**
Leave Admin is for admins. Staff see their own leave on [My Leave]({{ site.baseurl }}/docs/app/my-leave/).
