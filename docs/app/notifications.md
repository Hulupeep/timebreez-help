# Notifications Help

## What It Does

Configure how and when you receive alerts - email, push notifications, and WhatsApp messages.

## Why It Matters

Get the right information at the right time. Stay informed without being overwhelmed.

## How To Use It

1. **Enable or disable** notification channels
2. Choose which **events trigger alerts**
3. Set **quiet hours** if needed

## Tips

- Enable push notifications for time-sensitive alerts
- Managers should enable leave request notifications
