# Notifications Help

{: .note }
This page has not been checked against the current app yet. The pages listed under [Page by page]({{ site.baseurl }}/docs/app/) as checked are up to date.


## What It Does

Configure how and when you receive alerts: email, push notifications, and the messaging app you connect (for example Telegram). That column is called **Messaging app**.

## Why It Matters

Get the right information at the right time. Stay informed without being overwhelmed.

## How To Use It

1. **Enable or disable** notification channels
2. Choose which **events trigger alerts**
3. Set **quiet hours** if needed

## Tips

- Enable push notifications for time-sensitive alerts
- Managers should enable leave request notifications
