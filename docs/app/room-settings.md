# Room Settings Help

## What It Does

Configure detailed settings for each room - colors, staffing ratios, and operational requirements.

## Why It Matters

Fine-tune each room's configuration to match real-world needs. Different rooms often have different regulations.

## How To Use It

1. Select the **room** you want to configure
2. Adjust the **display color**
3. Set **minimum and maximum staff levels**
4. Configure any **room-specific rules**
5. **Save** your changes

## Tips

- Review ratio requirements for your sector
- Update settings when regulations change
