# Page by page
{: .fs-9 }

Help for each page of Timebreez. In the app, the **?** button at the top of every page opens the help for that page, with an assistant that knows which page and step you are on and walks you through it.
{: .fs-6 .fw-300 }

## Checked against the app (November 2026)

These are the pages you use to go live. Each was written from the app as it is now.

| Page | Who | What you do there |
|---|---|---|
| [Timetastic import]({{ site.baseurl }}/docs/app/timetastic-import/) | Admin | Bring staff, allowances and leave across, five people at a time |
| [Rule book]({{ site.baseurl }}/docs/app/rule-book/) | Admin | Read your rules and confirm, query or correct each one |
| [Settings]({{ site.baseurl }}/docs/app/settings/) | Admin | Leave defaults and the calculation rules (full-time day, half days, holidays) |
| [Employees]({{ site.baseurl }}/docs/app/employees/) | Admin, manager | Working patterns, balances and corrections |
| [Leave admin]({{ site.baseurl }}/docs/app/leave-admin/) | Admin | One place for everything leave |
| [Leave requests]({{ site.baseurl }}/docs/app/leave-requests/) | Admin, manager | Review the calculation, then approve or deny |
| [Roster]({{ site.baseurl }}/docs/app/roster/) | Admin, manager | Build the week, copy last week, check cover |
| [Payroll]({{ site.baseurl }}/docs/app/payroll/) | Admin | Check the draft figures for a pay period |
| [My settings and Telegram]({{ site.baseurl }}/docs/app/my-settings/) | Everyone | Link Telegram, request leave with /off |
| [Staff app]({{ site.baseurl }}/docs/app/staff-app/) | Staff | Today, your schedule, your leave, your team |

The other pages in this section have not been checked yet. Each says so at the top.
